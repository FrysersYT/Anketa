## 🛡️ Система бана IP (НОВОЕ!)

Теперь в анкете есть **защита от спама!**

### Как это работает:

1. **Каждый пользователь** видит свой IP-адрес в интерфейсе
2. **Администратор может заблокировать** любой IP через сервер
3. **Заблокированный пользователь** видит красное уведомление

## 👥 Список пользователей (НОВОЕ!)

Теперь **любой пользователь** может посмотреть всех зарегистрированных пользователей!

### Как это работает:
- Кнопка **"👥 Пользователи"** в главном меню
- Показывает имя, дату регистрации и роли
- Сортировка по дате (новые сверху)
- Обновляется в реальном времени

- 🔵 **blue** - Модератор
- 🟢 **green** - Проверенный
- 🟡 **gold** - VIP
- 🟣 **purple** - Разработчик
- 🟠 **orange** - Специальный

## 📋 Команды для администратора (на сервере):

```bash
# Показать всех пользователей
python3 /root/ban_manager.py users

# Выдать тег
python3 /root/ban_manager.py addrole username "Role" "color"

# Сменить пароль
python3 /root/ban_manager.py chpass username newpass

# Удалить пользователя
python3 /root/ban_manager.py deluser username

# Заблокировать IP
python3 /root/ban_manager.py banip 95.27.***** "Спам"

# Разблокировать IP
python3 /root/ban_manager.py unbanip 95.27.*****

# Посмотреть баны
python3 /root/ban_manager.py banlist
